## 📖 Sobre

O **EduCalc** é uma **calculadora profissional de notas escolares**, desenvolvida para auxiliar **educadores** na gestão e no cálculo de notas. 🧮

O objetivo é tornar a administração dos dados acadêmicos mais **prática**, **precisa** e **eficiente**, reduzindo o trabalho manual e os erros nos cálculos.
